# ============================================================
# A股做T执行台 - Crontab 定时任务配置模板
# ============================================================
#
# 使用方法：
# 1. 查看 Node 绝对路径：which node  (例如 /usr/local/bin/node 或 /usr/bin/node)
# 2. 获取项目绝对路径：pwd  (例如 /data/tstock)
# 3. 编辑当前用户的 crontab: crontab -e
# 4. 将以下 3 行粘贴进去（注意替换 /data/tstock 和 node 路径），保存退出
# 5. 查看配置结果: crontab -l
#
# ------------------------------------------------------------
# 1) 工作日 09:26 - 集合竞价存档与弱参考校准 (开盘前准备)
26 9 * * 1-5 cd /data/tstock && env -u http_proxy -u https_proxy node timing_task/tasks/task_auction.js >> timing_task/logs/cron.log 2>&1

# 2) 工作日 14:30 - 尾盘黑马实时选股与发布 (尾盘半小时操作窗口)
30 14 * * 1-5 cd /data/tstock && env -u http_proxy -u https_proxy node timing_task/tasks/task_tail.js >> timing_task/logs/cron.log 2>&1

# 3) 工作日 15:10 - 收盘选股、双轨回算、计划与周五底仓发布 (闭盘全量计算)
10 15 * * 1-5 cd /data/tstock && env -u http_proxy -u https_proxy node timing_task/tasks/task_daily.js >> timing_task/logs/cron.log 2>&1
# ============================================================

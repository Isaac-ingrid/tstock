凡是出现数字的地方，这里都说明它的公式、来源，以及**哪些来自原文、哪些是补充设计**。

## 一、持仓与盈亏口径

### 1.1 输入字段

| 字段 | 含义 | 谁填 |
|---|---|---|
| 持仓成本 `cost` | 券商的当前成本价，或自己按加权算的均价 | 你填 |
| 持仓股数 `shares` | 当前持有股数 | 你填 |
| 可用现金 `cap` | 账户里未买股票的钱 | 你填（不填则按 0 处理） |

这三项与行情数据互不干涉：行情自动取，持仓你手填。**做T系统不需要知道你是什么时候买的、买过几次**，只要成本与股数正确即可。

### 1.2 计算口径

| 指标 | 公式 | 说明 |
|---|---|---|
| 持仓市值 | 现价 × 股数 | |
| 浮动盈亏 | (现价 − 成本) × 股数 | 账户事实，含未实现部分 |
| 浮动盈亏% | (现价 − 成本) ÷ 成本 | |
| 当日盈亏 | (现价 − 昨收) × 股数 | **口径为「当日持仓未变动」** |
| 做T累计已实现 | 台账内该股全部记录净额求和 | 已扣摩擦成本 FEE=0.0011 |
| 每股降本 | 做T累计 ÷ 持仓股数 | |
| 等效未做T成本 | 持仓成本 + 每股降本 | **反推值，仅用于直观感受，不参与任何计算** |
| 仓位占比 | 持仓市值 ÷ (持仓市值 + 可用现金) | 未填现金时显示 100% |

### 1.3 为什么这样设计（避免重复计算）

最容易搞错的地方是：做T赚的钱，到底算在「浮动盈亏」里还是「做T贡献」里？

本系统的处理是**两笔分开、互不重叠**：

- **浮动盈亏**只跟「成本 vs 现价」有关，衡量的是持仓本身的状态；
- **做T累计**只跟台账有关，衡量的是操作创造的已实现收益。

所以「当日盈亏」不含当天做T的已实现收益——那部分单独列在该股的「做T累计贡献」里。
「等效未做T成本」是给直觉用的参考值（如果一次T都没做，成本会在哪），**它不是会计口径，不要拿它去算盈亏**。

### 1.4 成本差异怎么办

如果你的券商成本价已经包含了做T的摊薄效果（多数券商是**移动加权平均**，会），
那么「持仓成本」填券商显示值即可，系统展示的「每股降本」是**额外**告诉你做T贡献了多少，
不会再从成本里减一次。这是刻意设计，避免二次扣减。

## 二、图表引擎（多周期）

### 2.1 可切换的周期

| 周期 | 数据接口 | 字段顺序 | 显示根数 |
|---|---|---|---|
| 分时 | `web.ifzq.gtimg.cn/appstock/app/minute/query` | `"HHMM 价格 累计量(手) 累计额(元)"` | 当日全部（约 242 点） |
| 1分 / 5分 / 15分 / 30分 / 60分 | `ifzq.gtimg.cn/appstock/app/kline/mkline` | `[时间YYYYMMDDHHmm, 开, 收, 高, 低, 量, {}, 换手%]` | 1分 240 / 其余 64 |
| 日K | `ifzq.gtimg.cn/appstock/app/fqkline/get` | `[日期, 开, 收, 高, 低, 量]` | 60 |
| 周K | 同上（`week`） | 同上 | 60 |
| 月K | 同上（`month`） | 同上 | 40 |

**两套字段顺序不同，必须分开解析**：日/周/月是「开收高低」，分钟是「开收高低」一致，但分钟多一个换手率尾字段。
一律取前复权（qfq）。

**指标跟着周期走**：切到周K，MA5 就是 5 周线、MACD 也是周线口径——这是刻意设计，
因为"周线级别是否走坏"和"日线级别是否走坏"是两个不同的问题，机械照搬日线指标会误判。

### 2.2 主图叠加（可开关）

| 叠加项 | 说明 |
|---|---|
| 均线 | MA5 / MA10 / MA20 / MA60（五日线、二十日线都在内） |
| BOLL | 布林通道上/中/下轨，带淡蓝填充 |
| 箱体 | 20 日箱顶 / 箱底（橙虚线，左侧带文字标签） |
| 成本 | 持仓成本线（紫虚线），未填成本时不画 |
| 支撑压力 | 由日线口径算出的支撑位、压力位（红=压力、绿=支撑，右侧内缘标注「压1/撑1」） |

价格轴的取值范围以**蜡烛高低点**为主体；叠加线只有落在「蜡烛区间 ±8%」以内才会纳入，
否则一条离得很远的 MA60 会把整张图压扁。这是刻意的取舍。

### 2.3 副图（可切换）

| 副图 | 内容 |
|---|---|
| 成交量 | **常显**：每分钟/每根的量柱 + VMA5 量均线（紫线，5 周期量均） |
| MACD | DIF / DEA 双线 + 红绿柱，零轴居中 |
| RSI | RSI6 / RSI12 / RSI24 三线，30 / 50 / 70 参考线，超买超卖区淡色底 |
| 分时模式 | 副图自动换成两层：① 每分钟成交量柱；② **放量倍数**（该分钟量 ÷ 当日均量），用来一眼找出放量时刻 |

### 2.4 分时图的坐标系

分时图与 K 线图是两套不同的坐标：

- 纵轴**以昨收为中轴上下对称**，自动按当日最大偏离取整，右侧同时给出价格与涨跌幅（±2%、±4% 刻度）；
- **价格线**：相对昨收着色（红=高于昨收，绿=低于昨收），并向昨收画淡色填充；
- **均价线**（橙）：权威算法是「累计成交额 ÷ 累计成交量」，不是简单算术平均 —— 它才是当日多空的真实成本线；
- **现价 vs 均价** 是分时图上最实用的一句话判断：价在均价上方=多方掌控，下方=空方掌控。

### 2.5 交互与今日 K 线的并入规则

鼠标悬停显示十字光标，并在画布顶部给出两行信息：第一行是时间/开高低收/涨跌/量，第二行是各指标在这根上的取值
（第二行会按可用宽度自动取舍，宁可少显示两项也不让文字溢出被裁切）。

**今日 K 线的并入规则**：只有当行情接口返回的时间戳确实是「今天」时才并入今日数据（覆盖或补一根）；
非交易日打开页面时，K 线保持最近一个交易日的状态，**不会插出一根假的今日 K 线**。

## 三、技术指标口径

### 3.1 均线 MA

- 简单移动平均（SMA），对前复权收盘价计算，**含当日实时价**。
- MA60 在不足 60 根时显示为空，不影响其余指标。

| 排列判定 | 条件 |
|---|---|
| 多头排列 | MA5 > MA10 > MA20，且 MA20 > MA60（若有） |
| 空头排列 | MA5 < MA10 < MA20，且 MA20 < MA60（若有） |
| 均线纠缠 | 其余情况 |

MA20 方向：比较今日 MA20 与前一日 MA20 的大小，得出向上 / 向下 / 走平，并给出斜率百分比。

### 3.2 MACD(12, 26, 9)

标准参数，与同花顺、东方财富一致：

```
EMA(n) 递推：EMA₁ = C₁，EMAᵢ = Cᵢ × k + EMAᵢ₋₁ × (1 − k)，k = 2/(n+1)
DIF = EMA12 − EMA26
DEA = DIF 的 EMA9
柱  = (DIF − DEA) × 2
```

| 信号 | 判定 |
|---|---|
| 金叉 | 昨日 DIF ≤ DEA，今日 DIF > DEA |
| 死叉 | 昨日 DIF ≥ DEA，今日 DIF < DEA |
| 零轴 | DIF > 0 为上方（强势区） |
| 柱状体连续放大 | 同号且绝对值逐日递增的天数 |
| 顶背驰（警示） | 近 20 日内价格创新高、但 DIF 高点早于价格高点 2 根以上，且区间涨幅 > 2% |

顶背驰只是一个**提示**，不构成卖出指令——它是"价升量减"的常见形态，需配合放量滞涨确认。

### 3.3 箱体

| 项目 | 口径 |
|---|---|
| 箱顶 | 最近 20 个交易日（**不含今日**）的最高价 |
| 箱底 | 最近 20 个交易日（**不含今日**）的最低价 |
| 箱内位置 | (现价 − 箱底) ÷ (箱顶 − 箱底) × 100%，0% = 贴箱底，100% = 贴箱顶 |
| 向上突破 | 现价 > 箱顶 × 1.005（留 0.5% 容错，过滤假突破） |
| 向下破位 | 现价 < 箱底 × 0.995 |
| 箱体收敛 | 最近 5 根振幅 < 前 15 根振幅 × 0.8 |

**为什么排除今日**：箱体描述的是"已经被市场确认的震荡区间"。把今天的波动算进去，箱顶箱底会随当日涨跌实时漂移，失去参照意义。

**位置分区**：>78% 贴近箱顶（阻力，宜减）｜<22% 贴近箱底（支撑，缩量可低吸）｜中间为中枢。

同时计算 60 日箱体作为中期参照（卡片内只展示 20 日，避免信息过载）。

### 3.4 破位监测（三档）

| 档位 | 触发条件 | 建议动作 |
|---|---|---|
| 严重 | 跌破 20 日箱底 | 停止做T，等站回箱内 |
| 严重 | 现价 < MA20 且 MA20 转头向下 | 禁止低吸，只做反弹减仓 |
| 中等 | 跌破 MA60 | 主动降低仓位 |
| 中等 | 跌破持仓成本 | 克制"接回"冲动，此时接回等于逆势加仓 |
| 提示 | 盘中破位、收盘收回 | 假破位诱空，次日不破反是机会 |

「盘中破位、收盘收回」这一条是**唯一偏多**的信号，单列出来是因为它与其余各条方向相反，混在一起会误导。

### 3.5 常态波动 ATR(14)

```
TR = max(当日高 − 当日低, |当日高 − 昨收|, |当日低 − 昨收|)
ATR = TR 的 14 日 Wilder 平滑
```

| 水平 | 阈值 |
|---|---|
| 充沛 | ATR ≥ 4% |
| 中等 | 3% ≤ ATR < 4% |
| 偏窄 | ATR < 3% |

**注意口径区别**：ATR 是"常态"波动水平，而做T第一闸门用的是**当日振幅**。两者含义不同、数值不必相等，卡片里会额外给出「今日振幅 ÷ ATR」的比值，说明今天波动是放大还是收缩。

### 3.6 量能

今日成交量 ÷ 前 5 日平均成交量（不含今日）。

| 倍数 | 判定 |
|---|---|
| > 1.5 | 放量（涨则上攻、跌则真抛压） |
| < 0.8 | 明显缩量 |
| 其余 | 量能平稳 |

### 3.7 布林线 BOLL(20, 2)

```
中轨 = MA20
标准差 σ = sqrt( Σ(收ᵢ − 中轨)² / 20 )      （总体标准差，与行情软件一致）
上轨 = 中轨 + 2σ      下轨 = 中轨 − 2σ
%B  = (现价 − 下轨) ÷ (上轨 − 下轨)          0 = 贴下轨，1 = 贴上轨
带宽 BW% = (上轨 − 下轨) ÷ 中轨 × 100
```

| %B | 判定 | 做法 |
|---|---|---|
| > 1.0 | 突破上轨（超买） | 不追买，反而考虑倒T减仓；强势票可"沿上轨走" |
| 0.8 – 1.0 | 贴近上轨 | 追买性价比低 |
| 0.2 – 0.8 | 通道中枢 | 多空不占便宜 |
| 0 – 0.2 | 贴近下轨 | 可分批低吸，跌破则认输 |
| < 0 | 跌破下轨（超卖） | 超卖≠见底，等缩量止跌K线 |

**带宽变化**比价格本身更早给信号：近 5 日带宽扩张 > 8% 说明变盘或行情启动；
收窄 > 8% 说明**挤压待变盘**，方向未定前不宜重仓。中轨（=MA20）是短线多空分水岭。

### 3.8 RSI 相对强弱(6 / 12 / 24)

```
RSI = 100 − 100 ÷ (1 + 平均涨幅 ÷ 平均跌幅)      平均值为 Wilder 平滑
分档 RSI6 看日内情绪、RSI12 看短期、RSI24 看中期
```

| RSI6 | 判定 |
|---|---|
| ≥ 80 | 严重超买，此处追买正T的胜率最差 |
| 70 – 80 | 超买，优先兑现 |
| 30 – 70 | 中性 |
| 20 – 30 | 超卖，符合正T入场前提之一（叠加缩量更好） |
| ≤ 20 | 严重超卖，反弹概率高，但趋势向下时"超卖可以更超卖"，只宜小仓快进快出 |

**三线同向才有效**，单线极端只作提示。页面上另有一条组合警示：
RSI6 > 75 但价格已跌破 MA5，属"高位钝化转弱"。

### 3.9 换手率

```
换手率 = 当日成交量(手) × 100 ÷ 流通股本(股) × 100%
```
优先采用行情接口给的官方值（字段 38），缺失时才用上面的公式自算（流通股本取字段 72）。

| 换手率 | 判定 | 对做T的含义 |
|---|---|---|
| ≥ 15% | 过热 | 筹码剧烈交换，易冲高回落，快进快出、绝不隔夜 |
| 8% – 15% | 高度活跃 | 价差空间大 |
| 3% – 8% | 活跃 | 适合做T的状态 |
| 1.5% – 3% | 正常 | 只做确定性最高的那一次 |
| < 1.5% | 清淡 | 日内几乎没有可做T的价差，空仓是更优解 |

**换手率是"这票今天值不值得做T"的第一道筛子**：振幅够但换手极低的票，挂单常常挂不上、成交价滑点大。

### 3.10 支撑位 / 压力位

八类来源自动汇总，再按「相邻 0.6% 合并成一档」去重，取最近三档：

| 来源 | 权重 |
|---|---|
| 60 日箱顶 / 箱底 | 4 |
| 60 日高点 / 60 日低点 | 5 |
| MA60 | 4 |
| 20 日箱顶 / 箱底 | 3 |
| MA20、布林中轨、20 日高点 / 20 日低点、持仓成本 | 3 |
| MA5、MA10、布林上轨 / 下轨 | 2 |

合并后累加权重，标为「强 / 中 / 弱」；高于现价 0.1% 以上归为**压力**，低于现价 0.1% 以下归为**支撑**，
并给出距现价的百分比。

**用法**：买单挂在支撑位**上方一点**、卖单挂在压力位**下方一点** —— 不要挂在价位本身，那里往往一堆人排队。
多档重合（强度"强"）的位置最值得重视。注意：支撑压力是对**过去价格**的归纳，不含预测成分，
箱体下沿被反复测试后，被跌破的概率是**上升**而不是下降。

## 四、大单资金（逐笔本地统计）

### 4.1 数据来源与获取方式

腾讯逐笔成交接口 `stock.gtimg.cn/data/index.php?appn=detail&action=data&c=<code>&p=<页号>`。

两个坑（都已处理）：

1. **该接口没有 CORS 头**，`fetch` 会被浏览器拦掉；但它的响应体形如
   `v_detail_data_sh605128=[页号,"序号/时间/价/涨跌/手数/金额/方向|..."]`，是一条赋值语句，
   所以用 `<script>` 注入可以拿到（实测 Content-Type 为 text/html 也照样执行）。
2. **所有页都写同一个全局变量名**，并发拉取时谁后到谁覆盖。解法是在 `window` 上先用
   `Object.defineProperty` 给这个变量名挂一个 setter 劫持赋值，数据一到就按页号收走 ——
   于是全部页面可以并行拉，实测 21 页约 240ms。

每页 70 笔；分波并行（8 个一波），某一波一页都没回来即判定全天取完、立即停止；上限 60 页（≈4200 笔）。

### 4.2 分档口径（与东财一致）

| 档位 | 单笔成交金额 |
|---|---|
| 特大单 | ≥ 100 万 |
| 大单 | 20 万 – 100 万 |
| 中单 | 4 万 – 20 万 |
| 小单 | < 4 万 |

- **主力 = 特大单 + 大单**
- **净额 = 主动买 − 主动卖**；方向由接口给的 `B/S/M` 标记决定，**M（中性单）不计入方向**
- 净量同法计算（单位：手）

### 4.3 样本覆盖率（重要）

逐笔接口有页数上限。卡片会拿**行情接口给的官方成交额**（字段 37，单位万元）当分母校验：

```
覆盖率 = 样本合计成交额 ÷ 官方成交额 × 100%
覆盖率 ≥ 95% → 视为全天口径，分档金额可直接使用
覆盖率 < 95% → 明确标注"⚠️ 样本不完整"，此时只看资金方向与占比，不要当精确金额
```

实测上海沿浦（1595 笔）覆盖率 100.0%，与官方成交额 1.08 亿完全吻合，说明逐笔是全量而非抽样。

### 4.4 怎么读这张卡

| 主力净额占样本成交额 | 含义 |
|---|---|
| > +3% | 资金明确进场，回调承接力强，正T胜率更高 |
| −3% ~ +3% | 存量博弈，做T只赚波动不赚趋势 |
| < −3% | 资金持续流出，反弹高度受限，**只做倒T、不低吸** |

四条经验，供参考（均为统计倾向，不是必然）：

1. **价跌 + 主力净流出** = 真跌，不接；
2. **价跌 + 主力净流入** = 洗盘嫌疑，缩量到地量可试；
3. **价涨 + 主力净流入** = 健康上攻，回踩即机会；
4. **价涨 + 主力净流出** = 拉高出货，此时做倒T比做正T安全。

## 五、技术面综合评分

基准 50 分，七项加权：

| 项目 | 加分 | 减分 |
|---|---|---|
| 均线排列 | 多头 +15 | 空头 −18 |
| MACD | 金叉 +12，零轴上 +6 | 死叉 −12，零轴下 −6 |
| 箱体 | 上破 +10；箱内按位置 +0～6 | 下破 −15 |

## 七、已知限制

1. **数据为公开行情接口**，非交易所直连，秒级延迟；不适合高频或套利级决策。
2. **前复权数据**在发生分红送转时会重算历史，若你此前记录过绝对价位，需按新复权价重新理解。
3. **箱体、均线与支撑压力都是对过去的价格描述**，不含任何预测成分。箱体下沿被反复测试后，被跌破的概率会上升，而不是下降——这是本工具只把它当"参照"而非"保证"的原因。
4. 技术评分仅由价量数据推导，**不包含基本面、消息面**。遇到重大事件（并购、监管、业绩暴雷）时，任何技术指标都会失效。
5. **分钟级 K 线**（1/5/15/30/60 分）由接口按固定根数返回，最后一根是"当前未走完的周期"，其 OHLC 会随行情变动——这是正常现象，不是数据错误。
6. **逐笔大单**依赖第三方接口的页数上限。交投极活跃的个股可能取不全，此时卡片会标注"样本覆盖率"，请以资金**方向与占比**为主，不要当成全天精确金额。
7. **大单分档是"按单笔成交金额"划分的**，不等于"机构席位"。一笔 80 万的大单也可能是几个散户在同一毫秒的撮合结果；反过来，机构拆单后单笔可能只显示为中小单。这是所有按逐笔分档的软件共同的局限，**只能作为辅助，不能作为唯一依据**。

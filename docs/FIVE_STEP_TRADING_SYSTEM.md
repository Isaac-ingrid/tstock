# 五步交易系统量化规范（顺天时 · 抓主线 · 择良标 · 严执行 · 再重复）

本文档定义 `tstock` 交易工作台的核心实战体系与量化判定标准。整套系统只围绕一条自上而下的正期望漏斗运转，用客观规则替代盘中情绪化拍脑袋。

## 一、五步闭环总览

1. **第一步：看长期大趋势，择天时（定仓位生死）**
   - 锚定**上证指数 (`sh000001`)** 为核心基准，辅以深证成指 (`sz399001`)、创业板指 (`sz399006`)。
   - 识别指数处于 **上升结构 / 震荡结构 / 下跌结构**，叠加 **BOLL(20, 2) 上中下轨支撑压力** 与 **MACD(12,26,9) 顶底背离**。
   - 输出三档总仓位指令（与短线涨跌停情绪阀门联锁取严）：
     - **按兵不动（观望，0%~20% 仓位）**：指数下跌结构且无底背离，或超短情绪红灯退潮。大势不对，操作白费。
     - **派出先锋（小仓试错，30%~50% 仓位）**：指数震荡箱体、下跌末端出现底背离+布林下轨支撑、或上升途中出现顶背离/触碰布林上轨需防回踩。
     - **全力出击（重拳顺势，70%~80% 仓位）**：指数上升结构（站稳布林中轨且 MA20 向上）+ 无顶背离 + 情绪绿灯共振。

2. **第二步：看中期主线，找热点板块（定进攻方向）**
   - 在大盘基础上筛选**先于指数抗跌/领涨**（相对上证超额强度 `RS >= +1.2%`）且具备**大容量成交（板块核心成交容量充沛）+ 持续涨停梯队 + 资金抱团蓄势**的主线方向。
   - 划分板块四阶段生命周期，拒绝后知后觉追高：
     - `🌱 启动初期·优先介入`：先于指数走强，身位龙 `1~3` 板，涨停梯队初成，容量中军放量抬头。
     - `🔥 主升抱团·顺势低吸`：涨停梯队完整（`>=3` 家涨停）、板块容量充沛，围绕前排核心回踩低吸。
     - `⚠️ 高位一致·禁追高`：高标连板 `>=5` 板且板块大幅高潮换手过热，仅持筹锁盈，禁止后排追高接盘。
     - `⚖️ 分歧蓄势·去弱留强`：分化检验承接，仅盯抗跌活口。

3. **第三步：选小目标的，卡「五星游龙 × 涨停回调再突破」唯一模式**
   - 死磕唯一高胜率图形：**近 20 个交易日内出现涨停试盘建仓 → 随后缩量回调洗盘不破起涨底线 → 均线收敛蓄势待再度突破**。
   - 用 **五星游龙模型（满分 5.0 星，每维 1 星 / 20 分）** 硬卡标的成色，且优先做处于第二步热点主线中的共振标的：
     1. **趋势上行 (`starTrend`)**：股价站稳 MA20/布林中轨与试盘防守线，中长期均线拐头向上且周月线多头。
     2. **价值凸显 (`starValue`)**：非 ST、近 35 日公告零暴雷红牌，流动性与换手健康，具备基本面排雷与大资金认可。
     3. **上行空间足 (`starSpace`)**：距近 15 月高点未透支，且 210 日筹码分布上方套牢峰稀疏、突破阻力轻。
     4. **量价齐升 (`starVolPrice`)**：涨停试盘日放量突破 + 回调期极致缩量洗盘（量缩比达标）+ 月线级别温和放量。
     5. **筹码集中主力控盘 (`starChips`)**：210 日换手衰减 CYQ 90% 筹码集中度收敛、获利盘扎实、底仓锁仓良好。

4. **第四步：严格执行进退标准（先划止损 + 顶底背离买卖提示 + 破位收复观察）**
   - **选定第一件事先划止损线**：支持个股作战卡一键设定/微调硬止损价，以损定仓。
   - **顶底背离与布林买卖提示**：
     - **顶背离卖出/锁盈提示**：日线或分时股价创新高而 MACD DIF/红柱峰值走低（尤其触及布林上轨或压力卖区），果断高抛锁盈或减仓。
     - **底背离止跌买点提示**：股价回踩新低或布林中下轨支撑而 MACD DIF/绿柱抬高收敛，提示空头衰竭、右侧拐头试错。
   - **破位离场与收复再观察闭环**：有效跌破止损线无条件离场，自动转入「关键位收复观察池」静默隔离（绝不死扛补仓）；后续若放量重新站稳关键位（止损颈线 / 布林中轨），系统自动亮灯召回观察。

5. **第五步：复盘与总结（单模式 100 次 / 1000 次刻意重复）**
   - 每一笔实盘记录自动核对「顺天时 · 抓主线 · 择五星 · 守止损 · 模式内」五步合规度。
   - 在复盘教练页实时统计 **100 次里程碑 / 1000 次大成进度条**，并直观对比「五步合一规范单」与「破戒单」的真实胜率与净盈亏差额。

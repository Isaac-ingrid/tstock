核心结论：位置决定含义，量价决定真假。同一根K线、同一组量能，出现在高位是出货、出现在低位是吸筹；所有盘口"强势假象"的破绽都露在量价配合上。单一信号不下结论，多信号共振才可靠。

一、见顶信号特征（放量上涨后连续下跌等）

顶不是某一天形成的，而是"多方力量逐步衰竭 → 空方接管"的过程。

信号类别具体特征
量价高位放量滞涨（只放量不走价）；缩量创新高（顶背离）；冲高回落放量（诱多兑现）；连续下跌放量（恐慌加速）
K线形态长上影射星、高位十字星、乌云盖顶、黄昏之星、三只乌鸦；双顶/头肩顶/圆弧顶；跌破颈线、趋势线、20/30日均线且反抽不回
技术指标MACD顶背离+死叉；RSI/KDJ超买钝化后拐头；均线极度发散后粘合拐头
市场结构指数新高但上涨家数减少；龙头率先滞涨补跌、轮动加快；涨停数骤减、亏钱效应扩散
情绪资金融资余额高位回落、主力/北向持续净流出；开户暴增、爆款基金、媒体一致唱多（极端亢奋）；利好公布不涨（利好出尽）
基本面背离估值处历史高分位；周期股股价高点与业绩高点同步（业绩最好时往往是卖点）
三条避坑：① 脱离位置谈量价没有意义——低位放量是吸筹，高位放量可能是出货；② 超买钝化≠反转，拐头才是；③ 右侧确认优先——等破位+反抽不回再行动，宁可少赚不深套。

二、牛股梅开二度的成交量特征

梅开二度 = 第一波主升后经充分整理，再启动第二波。整理期量能有两条路径：巨量横盘与缩量横盘。

A 巨量横盘（换手承接型）

  • 第一波末段放巨量冲高，但不跟放量长阴——巨量是换手不是出货
  • 横盘期量大但阶梯萎缩；回调缩量、反弹温和放量
  • 重心持平微升，不破10/20日线，回调不深（0.382以内）
  • 二次启动：突破平台需1.5~2倍量并收盘站稳

B 持续缩量横盘（锁仓惜售型）

  • 量能缩至第一波高峰的1/4~1/3甚至更低，双向都缩量
  • K线实体小、排列紧密，重心水平，波动极窄
  • 含义：筹码高度锁定，浮筹极少——供给衰竭的极致
  • 二次启动：温和放量即可（浮筹少不要求天量），收中大阳站稳平台
维度A 巨量横盘B 缩量横盘
筹码结构浮筹充分交换，成本趋同高度锁定，浮筹极少
突破所需量能1.5~2倍放量消化获利盘温和放量即可
二波特点更稳、更持久更急、更凌厉，常连续拉升
主要风险换手变出货（放量下跌）人气耗散阴跌；大盘转弱时补跌快
失效边界放量跌破横盘下沿，或突破后放量回踩跌破平台——梅开二度逻辑作废
缩量横盘最大的坑：惜售 ≠ 无人问津。惜售型=主线龙头+题材/业绩支撑+横盘不回落+下探被快速收回；无人问津型=题材退潮+板块无跟随+重心阴跌——缩量只是没人关注，不是没人卖。

三、价格诡计：集合竞价与盘中行为

诡计手法识别要点
虚假涨停/跌停9:15-9:20大单高挂吓空/诱多，临近9:20撤单只看9:20-9:25竞价；撑不过9:20的单都是假的
开盘急拉回落放量冲高不维持，利用"要涨停"预期出货冲高放巨量、回落量不减、重心下移、反弹不过前高
开盘急砸拉起砸出"下方有支撑"假象，吓出止损盘再拉起接盘真洗盘量小、快速收回、能创新高；假支撑反弹无量、不过前高
放量后缩量阴跌放量滞涨完成出货后进入阴跌缩量≠没人卖，是买盘消失；"放量不涨→缩量阴跌"=出逃确认
尾盘竞价偷袭14:57后小资金拉高收盘价，为次日高开出货造空间控盘实力单薄的表现；次日高开不追，等回补

"横有多长，竖有多高"——这句谚语是诡计的镜像：主力低位吸筹横盘越久，锁定筹码越多，拉升空间越大。抓"狐狸尾巴"的正确姿势不是盯盘中诡计，而是提前蹲伏：长期低位横盘 + 波动收敛 + 股东户数下降（筹码集中）+ 温和放量突破横盘上沿且回踩缩量不破。

四、K线基础形态图解（十字星等）

每根K线由实体（开盘价—收盘价）与影线（最高/最低价）组成。A股配色：红=阳线（收>开），绿=阴线（收<开）。同一形态在不同位置含义相反，位置比形态本身更重要。

十字星
开盘价 ≈ 收盘价，上下影线相近

含义：开盘与收盘几乎同价，多空拉锯后回到原点——力量平衡被打破的临界点，常是趋势变盘的前兆。

高位出现（尤其长上影十字）：上方抛压重，见顶警示，先减仓或收紧止损，等次日确认

低位出现：下跌动能衰竭，止跌观察信号，需次日阳线确认再动手

变体：长上影十字（避雷针，高位最凶险）；T字/倒T字十字（单边试探）。

长上影线（射星/流星）
小实体 + 长上影，形似倒锤

含义：盘中冲高被大量卖单打回，收盘接近低位——上影线就是"上方卖压"的可视化。

高位长上影：典型见顶信号，配合放量更凶，常出现在主升末端

低位长上影：可能是主力试盘或洗盘，看后续能否快速收复上影

锤子线 / 上吊线
小实体 + 长下影（同形反义）

含义：盘中深跌后被买盘拉回，长下影证明"下方有承接"。

低位出现=锤子线：止跌反转信号，次日阳线确认则更可靠

高位出现=上吊线：名字即含义——主力借下影"展示支撑"吸引接盘，是出货警示

乌云盖顶 / 看跌吞噬
阳线之后大阴线反杀

含义：前一日阳线还给人希望，次日高开后一路低走，阴线实体插入前阳线实体一半以上——多头措手不及。

高位出现：强反转信号；若阴线完全吞没前实体（看跌吞噬），信号更强

黄昏之星
大阳 → 高位小星 → 大阴（三根组合）

含义：大阳冲顶 → 高位小星（多空僵持、上攻乏力）→ 大阴确认。三根K线讲完一个"由强转弱"的完整故事，是最经典的顶部组合形态之一。

高位出现：见顶确认度高，第三根阴线收盘通常已是最后的从容离场点

低位镜像：晨星（启明星）= 底部反转组合

三只乌鸦
高位连续三根阴线

含义：高位连续三根中阴、收盘价逐级走低——空头接管，接盘力量枯竭。

高位出现：下跌趋势启动信号，不宜抄底；配合放量破位则确定性更高

K线形态使用三原则：① 必须结合大周期与位置——同一根锤子线，低位是机会、高位是陷阱；② 等次一根K线确认——形态是概率不是铁律；③ 形态+量能互相印证——见顶形态配放量、止跌形态配缩量，可信度才高。

五、K线具体怎么看：什么时候买、什么时候卖

1. 一根K线先看三层

第一层 · 实体（动能）：开→收的距离就是多空对决的净结果。实体越长，赢的一方越坚决；实体很小（如十字星）= 势均力敌，变盘临界。

第二层 · 影线（争夺痕迹）：上影线=冲高被压回（上方有卖压），下影线=下探被拉起（下方有承接）。影线越长，代表该方向的力量越强。

第三层 · 位置 + 量能（含义开关）：同样的K线，涨了一大段后的高位=见顶语言，跌了很久后的低位=反转语言；再叠加量能——见顶形态配放量可信度高，止跌形态要缩量企稳。

多周期配合：周线定大势（牛熊）、日线定方向（趋势与关键位）、60分钟/30分钟找具体买卖点。大小周期矛盾时，长周期优先。

4. 四类经典卖点（触发 → 动作 → 例外）

卖点类型触发条件动作例外（可收回）
形态卖点高位长上影/十字星/乌云盖顶/黄昏之星先减仓，剩余仓位收紧止损次日大阳收复实体，形态失效
破位卖点放量跌破颈线/上升趋势线/20日均线，反抽不回清仓，不等反弹缩量假破位、次日快速收回可接回
背离卖点价格新高 + 量能萎缩 + MACD顶背离分批兑现利润后续放量消化背离则重新评估
阴跌卖点放量滞涨后进入缩量阴跌按主力出逃处理，不赌反弹重新放量收复失地再说
买卖的共同前提：买点必须"信号+位置+量能"三要素齐备，缺一个就等；卖点可以右侧执行——宁可少卖几个点，也不赌最高点。所有买入动作必须与预设止损同时发生，止损位只上移不下移。

5. 实战示例：K线序列演示（红=阳线，绿=阴线）

六、防守清单（每天开盘前后各过一遍）

  • 竞价只信 9:20–9:25 段，9:15 的异动一律打折；开盘 15–30 分钟内不急于操作
  • 开盘 30 分钟内不追放量冲高——等回落确认是诱多出货还是真突破
  • 急砸拉起的票，看反弹能否过前高、重心是否上移
  • 放量滞涨后出现缩量阴跌，按出货处理，不赌缩量见底
  • 尾盘偷袭拉升的票，次日高开是卖点参考而非买点
  • 高位十字星/长上影/乌云盖顶出现，先收紧止损或减仓，等确认
  • 梅开二度整理期，出现放量跌破平台下沿即认定逻辑作废
  • 任何单一信号不下结论：量价、形态、位置、市场环境四者共振才行动
